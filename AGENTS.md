# Agent Guide: zz-plant Profile Repo

This repository contains the GitHub profile configuration (`README.md` and associated visual assets) for the user **zz-plant** (Kanav Jain).

## Repository Purpose & Layout

- **Purpose**: Acts as the central portfolio profile showing projects (NextConsensus, Ethotechnics Studio, Refract, The Crumple Zone, Whether) and background context.
- **Assets**: The directory `docs/assets/` holds the social graphs, demo GIFs, and OG images used across portfolio websites (`kanav.net`, `nextconsensus.com`, `ethotechnics.com`, and `thecrumple.zone`).

## Core Rules & Conventions

1. **Portfolio Mapping**:
   - The selected repos table in `README.md` maps specific directory names (`signals`, `profile`, `cards`, `hex`, `archive`, `profile`) to repositories. Keep these names consistent.
2. **Visual Consistency**:
   - Any updates to the portfolio list must be accompanied by updating the social/GIF previews located inside `docs/assets/` to preserve visual coherence.
3. **No Code Files**:
   - Do not add software application source code directly to this repository. Maintain this purely as a portfolio and visual assets repository.
